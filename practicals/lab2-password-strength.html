Password security ek sabse fundamental cybersecurity concept hai. Yeh lab aapko real-time mein dikhata hai ki aapka password kitna strong hai, kitni der mein crack ho sakta hai, aur kya improvements karne chahiye. Samjho ki attackers kaise brute force aur dictionary attacks use karte hain.

Attacker Logic: Hackers pehle common passwords try karte hain (dictionary attack), phir brute force se har combination try karte hain. Password length aur character variety se crack time exponentially badhta hai.
Formula: Combinations = Charset_Size ^ Password_Length
