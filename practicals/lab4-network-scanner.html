📡 Network Reconnaissance & Port Scanning

Port scanning ek fundamental reconnaissance technique hai jisme network pe chalti services aur open ports dhundhe jaate hain. Attackers yeh information use karke vulnerabilities identify karte hain. Defenders isko apne network audit ke liye use karte hain. Nmap jaisa tool real world mein use hota hai — yahan hum iska simulation karenge.

Ports kya hain? Har computer mein 65535 ports hote hain. Har service ek specific port pe chalta hai.
Port 80 = HTTP | Port 443 = HTTPS | Port 22 = SSH | Port 21 = FTP | Port 3306 = MySQL
Open port: Service chal rahi hai — potential entry point
Filtered port: Firewall block kar raha hai
Closed port: Koi service nahi
