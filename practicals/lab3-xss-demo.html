💉 Cross-Site Scripting (XSS)

XSS ek web security vulnerability hai jisme attacker malicious JavaScript code ko webpage mein inject karta hai. Yeh code doosre users ke browsers mein execute hota hai. XSS se cookies steal ho sakti hain, keyloggers plant ho sakte hain, aur fake pages dikhaye ja sakte hain. OWASP Top 10 mein XSS ek major threat hai.

XSS Types:
🔴 Reflected XSS: URL mein script inject hoti hai, server wapas reflect karta hai
🟡 Stored XSS: Script database mein save hoti hai, sab users ko affect karti hai
🟢 DOM-based XSS: Client-side JavaScript mein manipulation
Impact: Cookie theft, session hijacking, phishing, keylogging

// 🛡️ HOW TO PREVENT XSS

1. Output Encoding
element.textContent = userInput; // innerHTML KABHI NAI use karo!
2. Content Security Policy (CSP)
Content-Security-Policy: default-src 'self'
3. HttpOnly Cookies
Set-Cookie: session=abc123; HttpOnly; Secure
4. Input Validation + Sanitization Libraries
DOMPurify.sanitize(userInput) — trusted library

  • Reflected, Stored, aur DOM-based XSS ka fark
  • innerHTML vs textContent ka security impact
  • Cookie theft aur session hijacking
  • CSP headers aur output encoding se prevention
